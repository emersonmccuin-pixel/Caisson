# T3.2b — Migrate the remaining 12 live-event-via-timeline consumers onto the live store

Theme 3, prerequisite for T3.3 (the cut). Branch `refactor/auto-pathway`. Web-only EXCEPT the
field-schema writer fix (Q1 option A — server+contracts, decided below).

## Goal
Move the last 12 UI reads that still positional-scan the chat `events[]` for relay `live-event`
frames onto the identity-keyed live store, so they update live during an active session. After this,
NO UI consumer reads relay live-event frames off the timeline — the safety precondition for T3.3.

**Reconcile-first:** migrate the reads only. Do NOT early-return live-event frames in the WS handler,
touch reducer admission, the cross-reset retention, or the `_events` param — that's T3.3, after this
lands + live-verifies.

## Selectors — all already exist; T3.2b adds NONE
- `useLiveEvents(entity, projectId)` → version-deduped `LiveEvent[]` (`{cursor, version, payload, entityId, ...}`). Use when payload/filter-by-id needed.
- `useLiveEntitySignature(entity, projectId)` → stable string, flips per real change. Use as a refetch trigger.
Precedent in tree: `use-project-pods.ts:38-41`, `use-project-areas.ts:47-50`.

## Writer-entityId audit (store eligibility) — verified
All consume entities already in the store (entityId = real id) EXCEPT **field-schema** (entityId
null always → store drops it). area DELETE carries the DTO → `entityId=area.id` → in store (only
`reorder` is null, and no consumer needs reorder).

## Q1 DECISION — field-schema: option A (writer fix)
`packages/app-services/src/work-items/gateway.ts:122` `buildFieldSchemasReplacedDraft` → set
`entityId: input.projectId` (field schemas are a per-project singleton list; projectId is the natural
key, mirrors `project-claude-md`). Update the contract `FieldSchemaListChangedLiveEvent.entityId`
(`packages/contracts/src/field-schemas.ts:64`) from `null` to `ULID`, and its guard (`:150`
`value.entityId === null` → `typeof value.entityId === 'string'`). NOT web-only → re-run contracts +
app-services + server tests. (Rejected option B: relaxing the store's null-entityId guard changes
shared semantics + would let area-reorder frames in.)
